Grammar points on page 62

1

～たら…

if ~ / when ~

  • Form: plain past form (～た / ～なかった) + ら
  • "If/when ~ is assumed, … happens." Often used with もし. This is the most flexible conditional: it can be followed by requests, invitations and the speaker's intentions.
  • Examples from the book:
    1. もし水みずがなかったら、わたしたちは生いきられません。 If there were no water, we couldn't live.
    2. もし大おおきいじしんが起おきたら、すぐつくえの下したに入はいってください。 If a big earthquake happens, get under a desk right away.
    3. あした天気てんきがよかったら、どこかへ行いきませんか。 If the weather's good tomorrow, shall we go somewhere?
2

～ば… / ～なら…

if ~

  • Form: ば-form / なら-form (see book p.20). Verbs: 乗のる → 乗のれば; い-adj: 暑あつい → 暑あつければ; nouns/な-adj: + なら.
  • "When the condition ~ is met, … happens." When ~ is an action verb, the second half can't be a request, invitation or the speaker's intention. Sometimes used with もし.
  • Examples from the book:
    1. バスに乗のれば、駅えきまで10分ふんです。 If you take the bus, it's 10 minutes to the station.
    2. じしょを使つかわなければ、この本ほんは読よめません。 If I don't use a dictionary, I can't read this book.
    3. もし暑あつければ、クーラーをつけましょうか。 If you're hot, shall I turn on the air conditioner?
    4. 子こどもの名前なまえは、男おとこの子こなら「こうた」、女おんなの子こなら「みちる」がいいです。 For the baby's name, "Kouta" would be good if it's a boy, and "Michiru" if it's a girl.
3

～と…

when ~ / whenever ~

  • Form: plain form (not past) + と
  • "When ~ happens, … always / naturally follows." The second half can't be a request, invitation or the speaker's intention.
  • Examples from the book:
    1. お金かねを入いれてボタンをおすと、きっぷが出でます。 When you put in money and press the button, a ticket comes out.
    2. ねむいと、頭あたまが働はたらきません。 When I'm sleepy, my brain doesn't work.
    3. Mサイズだと、小ちいさいです。Lサイズをください。 If it's a medium, it's too small. Please give me a large.
    4. あのかどを左ひだりにまがると、駅えきが見みえます。 When you turn left at that corner, you'll see the station.

Quick tip: Want to make a request, invitation or say what you'll do after "if"? Use たら. ば and と describe natural results, like rules, directions and machines.

Practice 18 questions
Instructions

　の中なかの言葉ことばを正ただしい形かたちにして、書かいてください。

Change the word in the brackets ( ) into the correct form and write it in the blank.

Q1 Write

おさけを　ら、運転うんてんしないでください。（飲のむ）

If you've been drinking alcohol, please don't drive.

Show answerHide answer
Answer飲のんだ（飲のんだら）

Grammarた form + ら

たら is the た form + ら: 飲のむ → 飲のんだ → 飲のんだら. It's followed by a request (しないでください), which only たら allows.

Osake o nondara, unten shinaide kudasai.

Q2 Write

今日きょうぜんぶ仕事しごとが　ら、あしたもつづきをします。（終おわる）

If I don't finish all the work today, I'll continue it tomorrow.

Show answerHide answer
Answer終おわらなかった（終おわらなかったら）

Grammar～なかったら (if not ~)

You'd only continue tomorrow if the work doesn't finish, so the negative: 終おわらなかったら.

Kyou zenbu shigoto ga owaranakattara, ashita mo tsuzuki o shimasu.

Q3 Write

家いえが　ば、そうじがたいへんです。（広ひろい）

If the house is big, cleaning is hard work.

Show answerHide answer
Answer広ひろけれ（広ひろければ）

Grammarい-adjective ば-form: ～ければ

広ひろい → 広ひろければ. The ば is already printed, so write 広ひろけれ.

Ie ga hirokereba, souji ga taihen desu.

Q4 Write

めがねを ①　ば、新聞しんぶんが読よめますが、②　ば、ぜんぜん読よめません。（かける）

If I wear glasses, I can read the newspaper, but if I don't, I can't read it at all.

Show answerHide answer
Answer① かけれ（かければ） ② かけなけれ（かけなければ）

GrammarVerb ば-form, positive and negative

かける (Group II) → かければ. Negative: かけない → かけなければ.

Megane o kakereba, shinbun ga yomemasu ga, kakenakereba, zenzen yomemasen.

Q5 Write

天気てんきが　ば、ここから富士山ふじさんが見みえます。（いい）

If the weather is good, you can see Mt. Fuji from here.

Show answerHide answer
Answerよけれ（よければ）

GrammarException: いい → よければ

いい uses よ- for its forms: よければ (not いければ).

Tenki ga yokereba, koko kara Fujisan ga miemasu.

Q6 Write

日曜日にちようびの　なら、時間じかんがあります。（午後ごご）

If it's Sunday afternoon, I have time.

Show answerHide answer
Answer午後ごご（午後ごごなら）

GrammarNoun + なら

Nouns connect directly to なら.

Nichiyoubi no gogo nara, jikan ga arimasu.

Q7 Write

このどうぐが　と、べんりです。（ある）

If you have this tool, it's convenient.

Show answerHide answer
Answerある（あると）

GrammarDictionary form + と

と takes the plain non-past form: あると.

Kono dougu ga aru to, benri desu.

Q8 Write

休やすみ時間じかんが　と、ゆっくり休やすめません。（短みじかい）

When the break is short, you can't rest properly.

Show answerHide answer
Answer短みじかい（短みじかいと）

Grammarい-adjective + と

い-adjectives connect directly to と.

Yasumi jikan ga mijikai to, yukkuri yasumemasen.

れんしゅう2

Practice 26 questions
Instructions

いちばんいいものをえらんでください。

Choose the best option.

Q1 Choose

いいアイディアが　、教おしえてください。

If you have a good idea, please tell me.

Show answerHide answer
Answerb. あったら

Grammarたら + request

The second half is a request (教おしえてください). Only たら can be followed by a request. a と can't. c あって is a reason/sequence, not a condition.

Ii aidia ga attara, oshiete kudasai.

Q2 Choose

トム「すみません、ゆうびんきょくはどこですか。」
女おんなの人ひと「ここをまっすぐ　、右みぎにまがると、あります。」

Tom: "Excuse me, where's the post office?"
Woman: "Go straight along here, and when you turn right, it's there."

Show answerHide answer
Answerb. 行いって

Grammarて form for a sequence of steps

Directions list steps in order: "go straight, (then) turn right." The て form connects steps. a would put two と conditions in a row, which is awkward. c とき ("at the time when") doesn't fit directions.

Onna no hito: "Koko o massugu itte, migi ni magaru to, arimasu."

Q3 Choose

このこうえんは、春はるになると、　。

In this park, when spring comes, the cherry blossoms are beautiful.

Show answerHide answer
Answera. さくらがきれいです

Grammarと + natural result (no invitations/wishes)

と shows a natural, regular result: "When spring comes, the blossoms are pretty." b (invitation) and c (the speaker's wish) can't follow と.

Kono kouen wa, haru ni naru to, sakura ga kirei desu.

Q4 Choose

説明せつめいをよく読よめば、すぐ　。

If you read the explanation carefully, you'll understand the answer right away.

Show answerHide answer
Answerc. 答こたえがわかりますよ

GrammarAction verb + ば → no request/intention after

読よむ is an action verb, so after ば you can't put a request or your intention. わかる is a natural result, so it works. a is a request. b 答こたえます is an intentional action.

Setsumei o yoku yomeba, sugu kotae ga wakarimasu yo.

Q5 Choose

勉強べんきょうをがんばれば、　。

If you study hard, you can get good marks.

Show answerHide answer
Answera. いいてんがとれます

Grammarば + natural result

がんばる is an action verb, so the result must be a natural outcome, not the speaker's intention or wish. "You can get good marks" is a result. b is the speaker's intention. c is a wish.

Benkyou o ganbareba, ii ten ga toremasu.

Q6 Choose

まんがを　、このペンを使つかいます。

When I draw manga, I use this pen.

Show answerHide answer
Answerc. かくとき

Grammar～とき (at the time when)

You use the pen while drawing, so "at the time when I draw" = かくとき. a かいたら = "after I've drawn," which is the wrong timing. b と can't be followed by the speaker's own intentional action (使つかいます).

Manga o kaku toki, kono pen o tsukaimasu.
